# Day 4 - Environment Variables in Jenkins

## Goal
Use environment variables inside a Jenkins pipeline

## What I Did
- Defined variables using `environment`
- Used variables in both `echo` and `sh` steps

## Variables Used
- MESSAGE → stores a text message  
- FILE_NAME → stores file name  

## Pipeline Stages
1. Print Variable → prints MESSAGE  
2. Use Variable → creates file using variables  
3. Read File → displays file content  

## Output
- Message printed
- File created using variable
- Content displayed successfully
